# Security

keyshare is security-critical software: threshold signing and policy enforcement for wallets that can move funds. This repository is in the design phase. Nothing here has been implemented or audited. Do not put real funds behind any future code from this repo until it has been independently audited and the project says it is ready.

## Reporting a vulnerability

Report security issues privately to [chad@loreum.org](mailto:chad@loreum.org). Do not open a public GitHub issue for a suspected vulnerability.
